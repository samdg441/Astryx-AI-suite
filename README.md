# 🌌 Astryx AI Suite

Astryx AI Suite es una plataforma conceptual de gestión de inteligencia artificial que centraliza el acceso a múltiples herramientas de IA premium en una sola suscripción.

Este proyecto fue desarrollado como sitio web empresarial demostrativo, con enfoque en diseño futurista, minimalista y tecnológico.

---

## 🚀 Objetivo del proyecto

Simular una startup tecnológica que ofrece:

- Acceso centralizado a múltiples IAs
- Planes de suscripción
- Plataforma moderna y escalable
- Experiencia visual premium

---

## 🧩 Estructura del sitio

El sitio incluye:

- **Index** → Presentación de la empresa
- **Sobre Nosotros** → Equipo, misión, visión y objetivos
- **Productos** → Planes y servicios
- **Contáctenos** → Formulario y ubicación

---

## 🛠 Tecnologías usadas

- HTML5
- CSS3
- (Preparado para escalar a JavaScript y React)
